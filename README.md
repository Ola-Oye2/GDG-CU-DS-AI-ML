Welcome to the **GDG CU Data Science, AI & ML Track** — a weekly challenge-based repository where you level up from Python fundamentals to building real-world AI and Machine Learning projects.

## 🚀 How to Participate

Follow these steps for **every** mission to submit your work for grading:

1. **Fork** this repository by clicking the *Fork* button at the top-right of this page.
2. **Clone** your fork to your local machine:
   ```bash
   git clone https://github.com/<your-username>/GDG-CU-DS-AI-ML.git
   cd GDG-CU-DS-AI-ML
   ```
3. **Create a branch** named after the mission you are working on:
   ```bash
   git checkout -b mission-01-submission
   ```
4. **Complete the code** inside the relevant mission folder (e.g. `mission_01/`). Edit `starter_code.py` to implement the full solution.
5. **Push** your branch to your fork:
   ```bash
   git add .
   git commit -m "Complete Mission 01 submission"
   git push origin mission-01-submission
   ```
6. **Open a Pull Request** from your fork's `mission-01-submission` branch back to the `main` branch of this repository for grading.
